Projetos

Fila de entrega e acompanhamento em tempo real
Para que serve: aqui você cadastra e acompanha cada trabalho (site, loja, landing…). Tudo que você mudar aparece na hora pro cliente no portal dele — em tempo real, sem ele precisar atualizar a página.
Passo a passo:
  1. Criar o projeto: clique em + Novo projeto, preencha o nome do cliente, o tipo de serviço, o valor e a chave PIX, e clique em Salvar. O sistema gera um código pro cliente.
  2. Enviar o código: mande o código pro cliente pela Caixa de entrada (chat).
  3. Atualizar o andamento: use Avançar etapa (Novo → Andamento → Aguard. PIX → Pago → Entregue) ou os botões de status. O cliente vê a mudança na hora.
  4. Marcar o pagamento: quando o PIX cair, clique em Marcar pago (ou avance a etapa).
  5. WhatsApp: em cada projeto/contato há atalho com mensagem pronta.
  6. Entregar o projeto: cole o endereço no Link de entrega e salve. O cliente vê "Acessar meu site" no portal.
